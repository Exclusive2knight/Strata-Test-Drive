# Strata Test Drive

A realistic driving simulator that runs in your browser: 541 real trims with their real drive modes and suspension, a city, a freeway with interchanges, a double-helix parking garage, a proving ground, AI traffic and pedestrians.

**Play:** https://exclusive2knight.github.io/Strata-Test-Drive/

## Working on it

The game source is `src/app_template.html`. Run `python3 build.py` to rebuild `index.html`, which GitHub Pages serves. See `CLAUDE.md` for the full workflow, tests and screenshot tools.
